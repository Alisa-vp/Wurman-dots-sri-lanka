# Карта плотности населения с использованием пропорциональных символов
# Задачи:
Наглядно показать неравномерность распределения населения на территории Шри-Ланки.
# Данные:
Источник: Растр с данными о населении острова Шри-Ланка - https://hub.worldpop.org/geodata/summary?id=72880.
Исходная проекция: географическая (градусы) - EPSG:4326 - WGS 84
Целевая проекция: EPSG:32644 - WGS 84 / UTM zone 44N
# Метод:
1. Обрезка растра и перепроецирование данных. Растр был обрезан по векторному слою границы о-ва Шри-Ланка, а затем перепроецирован в СК. EPSG:32644 - WGS 84 / UTM zone 44N для дальнейших действий по заданию размеров сетки и буферов в метрах, а не в градусах, и обеспечения точности пространственных расчётов.
2. Построение регулярной сетки. Через инструмент «Вектор → Обработка геометрии → Сетка» построена регулярная сетка с размером ячейки 10 000 метров (10 км).
3. Расчёт центроидов. Для каждой ячейки сетки построен центроид.
4. Расчёт атрибута buf_sum. В таблице центроидов создано новое поле buf_sum, значение которого вычислялось по формуле:
buf_sum = pop_sum / 300302 * 4900,
Где:
pop_sum — суммарное население в ячейке
300302 — нормировочный коэффициент (референсное значение, соответствующее максимальному населению)
4900 — базовый радиус буфера в метрах. Этот шаг превращает абсолютные значения населения в пропорциональные радиусы буферов.
5. Буферизация по атрибуту. Через «Вектор → Геообработка → Буферизация» созданы буферы, радиус которых задаётся по атрибуту buf_sum. Исходный радиус должен был составлять 5 000 м (половина размера ячейки), но для эстетики карты он был немного уменьшен до 4 900 м, чтобы символы не сливались в сплошное пятно. В результате каждая точка получает размер, пропорциональный населению в её ячейке.
6. Оформление карты. Финальная карта оформлена с легендой, масштабной линейкой и подписями. Размер символов наглядно показывает зоны наибольшей концентрации населения.
